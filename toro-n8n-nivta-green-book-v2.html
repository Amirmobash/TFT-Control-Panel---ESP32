Toro N8N: Fußball‑Roboter für Kinder

Du baust einen n8n‑Workflow, der Bundesliga‑Daten (OpenLigaDB) abruft, dein Team findet (z. B. Bayern), daraus eine kurze Nachricht baut und sie per HTTP an Telegram sendet – ohne Telegram‑Trigger.

node6 — Build Last Match Message Run Once for All Items · JavaScript
▾
Erzeugt message inklusive Ergebnis (Sieg/Unentschieden/Niederlage).
// (z.B. "Bayern") - kommt aus dem Set-Node
const teamKeyword = $json.teamKeyword || 'Bayern';

// Teamnamen & Datum aus dem Match-Objekt
const team1Name = $json.team1?.teamName ?? '';
const team2Name = $json.team2?.teamName ?? '';
const matchDateTime = $json.matchDateTime ?? '';

// Alle Ergebnisse (z.B. Halbzeit, Endergebnis)
const matchResults = $json.matchResults ?? [];


const endResult =
  matchResults.find(r => r.resultTypeID === 2) ||
  matchResults.find(r => (r.resultName || '').toLowerCase().includes('end'));

const pointsTeam1 = endResult?.pointsTeam1;
const pointsTeam2 = endResult?.pointsTeam2;

// Falls wir kein Endergebnis finden, geben wir eine sichere Nachricht zurück
if (pointsTeam1 === undefined || pointsTeam2 === undefined) {
  return [
    {
      json: {
        message:
          `Letztes Spiel von ${teamKeyword} gefunden, aber das Endergebnis fehlt.
` +
          `${team1Name} vs ${team2Name}
` +
          `Zeit: ${matchDateTime}`
      }
    }
  ];
}

// Prüfen: Ist unser Team Team 1 oder Team 2?
const istTeam1 =
  team1Name.toLowerCase().includes(teamKeyword.toLowerCase());

const meinTor = istTeam1 ? pointsTeam1 : pointsTeam2;
const gegnerTor = istTeam1 ? pointsTeam2 : pointsTeam1;

// Ergebnistext bauen 
let ergebnisText = 'Unentschieden 🤝';
if (meinTor > gegnerTor) ergebnisText = 'Sieg ✅';
if (meinTor < gegnerTor) ergebnisText = 'Niederlage ❌';

// Finale Nachricht
return [
  {
    json: {
      message:
        `Letztes Spiel von ${teamKeyword}:
` +
        `${team1Name} ${pointsTeam1}-${pointsTeam2} ${team2Name}
` +
        `Ergebnis: ${ergebnisText}
` +
        `Zeit: ${matchDateTime}`
    }
  }
];

2) Final node — Telegram senden

HTTP Request1 · POST
Der letzte Node sendet den Text aus {{$json.message}} an Telegram. Du nutzt Query‑Parameter (chat_id + text). 
HTTP Request1
Method: POST

URL: https://api.telegram.org/bot(DEIN_TOKEN)/sendMessage

Send Query Parameters: On
Specify Query Parameters: Using Fields Below

Name: chat_id
Value: Deine ID

Add Parameter:
Name: text
Value: {{$json.message}}
Wichtig: Token & Chat‑ID sind privat. Im Buch immer Platzhalter verwenden.
Merksatz: message wird gebaut → Merge → Telegram sendet text.
